# CodeAlpha_TaskAutomationWithPythonScripts 
# Task 3: Task Automation with Python Scripts

## Objective
Automate a small real-life repetitive task using Python.

## Selected Idea
Move all JPG image files from a source folder to a destination folder.

## Features
- Reads files from the source folder
- Detects JPG image files
- Moves files automatically
- Creates the destination folder if it does not exist
- Displays successful transfer messages

## Key Concepts Used
- os module
- shutil module
- File Handling

## Requirements
- Python 3.x

## How to Run
1. Update the source and destination folder paths.
2. Open the project in Visual Studio Code.
3. Run the Python file.
4. JPG files will be moved automatically.

## Note
GitHub Codespaces usage limit was reached. 
Please run the project locally using VS Code + Python 3.

## Sample Output
```
Moved: image1.jpg
Moved: image2.jpg
Moved: image3.jpg

Task Completed Successfully!
```

## Conclusion
This project automates file management using Python and demonstrates the use of file handling along with the os and shutil modules.
